Industrial collaboration: Johnson & Johnson
01

Overview

The osmsotic pump device is a drug delivery device in which release kinetics are governed by the interplay of osmotic pressure, dissolution, convective and diffusion mass transport, across two distinct internal regions connected by an orifice.

A 2D multiphysics CFD model was developed in COMSOL and coupled to a Python automation (mph library), enabling systematic parametric studies, RMSE-based accuracy evaluation against experimental data, and a Bayesian smart optimization loop that feeds a machine learning surrogate pipeline (RFR and GBR).

The work spanned six iterative research phases, culminating in the identification of a transport mechanism and a fully automated CFD-to-ML framework.

Challenge & Approach

Challenges

  • Standard CFD systematically underpredicted release rates — root cause unknown across multiple modeling iterations
  • Dynamic solid–liquid interface during dissolution changes the fluid cross-section over time, altering convective flux
  • Release kinetics depend on multiple coupled, time-varying physical properties
  • Large parameter space makes exhaustive CFD sweeps computationally prohibitive
  • Industry-proposed transport hypothesis required rigorous force-balance verification

Approach

  • Built a 2D COMSOL model coupling Navier–Stokes, convection–diffusion, dissolution ODEs, and osmotic pressure
  • Derived a time-dependent convective flux modifier from the evolving solid-liquid interface
  • Introduced dynamic property functions replacing fixed scalar assumptions
  • Automated full simulation pipeline via Python–COMSOL API with RMSE evaluation at each iteration
  • Designed Bayesian optimization loop → ML surrogate layer (Random Forest ) to replace expensive CFD runs

Novel Mechanism · Transport

S–L Interface Discovery

Identified a previously unmodeled mechanism: as solid material dissolves, the fluid cross-section widens over time — dynamically changing convective flux. A time-dependent modifier function derived from this resolves the systematic underprediction.

Variable Property Modeling

Replaced fixed scalar property assumptions with dynamic functions of local concentration, time, and operating conditions. Variable property models achieved lower RMSE for both compartment release profiles and closed the mass balance.

Force Analysis · Hypothesis Testing

Particle Transport Verification

Rigorously evaluated a proposed transport mechanism via force balance (gravity, buoyancy, pressure). Analysis showed the particles are non-buoyant — gravity exceeds buoyancy — contradicting the hypothesis and redirecting modeling focus to convective flow.

Key Results

Full-physics 2D model validated against experimental data Navier–Stokes, convection–diffusion, PBM dissolution, and osmotic pressure all coupled within a 2576-element structured mesh — with mass balance satisfied for both device compartments.
Novel S–L interface mechanism identified & resolved Time-dependent convective flux modifier derived from the evolving solid–liquid interface resolved the systematic underprediction that persisted across all prior modeling iterations.
Zero-intervention parametric pipeline built Python–COMSOL API integration enables fully automated sweeps over any parameter space — with RMSE tracking and file archiving at every iteration, removing all manual overhead.
Mass balance closed via variable property modeling Replacing scalar property assumptions with dynamic functions of local state reduced RMSE and closed a previously open mass balance discrepancy in the osmotic compartment.
Transport hypothesis tested & mechanistically resolved Force balance analysis (gravity, buoyancy, pressure) disproved an industry-proposed particle transport mechanism, redirecting focus and improving model accuracy.
ML surrogate architecture designed for CFD acceleration Random Forest + PINN surrogate roadmapped to replace expensive finite-element parametric runs — enabling real-time design space exploration once training data is sufficient.
