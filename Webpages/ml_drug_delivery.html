01

Overview

The osmotic pump device controls drug release through interplay of osmotic pressure, dissolution, and convective/diffusive mass transport across two compartments connected by a micro-orifice.

A 2D COMSOL multiphysics model was coupled to a Python automation pipeline — enabling parametric sweeps, RMSE-based validation, and Bayesian-guided ML surrogate training (Random Forest + PINN) across six iterative research phases.

Challenge & Approach

⚠️ Challenges

  • CFD systematically underpredicted release rates — root cause unknown
  • Dissolving solid changes fluid cross-section over time, altering convective flux
  • Coupled, time-varying physical properties govern kinetics
  • Large parameter space makes exhaustive CFD sweeps expensive
  • Industry-proposed transport hypothesis required force-balance verification

💡 Approach

  • 2D COMSOL model coupling Navier–Stokes, convection–diffusion, PBM, and osmotic pressure
  • Time-dependent convective flux modifier derived from the evolving S–L interface
  • Dynamic property functions replacing fixed scalar assumptions
  • Python–COMSOL API pipeline with RMSE evaluation at each iteration
  • Bayesian optimization loop feeding RF + PINN surrogate layer

Modeling Phases

🔲 COMSOL · CFD · PBM

2D Multiphysics Model

Navier–Stokes flow, convection–diffusion mass transport, and Population Balance dissolution — all within a 2576-element structured mesh capturing both compartments and the orifice.

COMSOLN–SPBM🔒 Confidential
🔍 Novel Mechanism

S–L Interface Discovery

As solid dissolves, the fluid cross-section widens — dynamically reducing convective velocity. A time-dependent modifier derived from this mechanism resolved the persistent underprediction.

TransportCOMSOL🔒 Confidential
⚙️ Python · COMSOL API

Automated Parametric Pipeline

Python–COMSOL API bridge runs full simulations without manual steps — sweeping parameters, computing RMSE against experimental data, and auto-archiving results at each iteration.

PythonAPIRMSE🔒 Confidential
📈 Validation · Properties

Variable Property Modeling

Replaced fixed scalars with dynamic functions of local concentration and time. Variable properties reduced RMSE for both compartment profiles and closed a previously open mass balance.

COMSOLPythonRMSE🔒 Confidential
⚖️ Force Analysis

Particle Transport Verification

Force balance (gravity, buoyancy, ΔP ≈ 65 Pa pressure) showed particles are non-buoyant — gravity exceeds buoyancy — disproving an industry-proposed mechanism and refocusing on convective flow.

PhysicsAnalysis🔒 Confidential

ML Surrogate Architecture

CFD sweep outputs serve as labeled training data. Random Forest captures nonlinear parameter relationships; PINNs embed governing equations as loss constraints — enabling real-time design exploration.

Full-physics 2D model validated N–S, convection–diffusion, PBM dissolution, and osmotic pressure coupled in a 2576-element mesh with mass balance satisfied for both compartments.
