Project Overview

This project addresses a core industrial challenge: predicting and optimizing the release kinetics of a dual-drug osmotic pump device designed for sustained, localized therapy. The device co-delivers an active pharmaceutical ingredient and an osmotic agent through separate compartments, where the interplay of dissolution, convection, and diffusion governs therapeutic efficacy.

A 2D multiphysics CFD model was developed in COMSOL, tightly coupled to a Python automation layer that orchestrates parametric sweeps, evaluates model accuracy against experimental dissolution data, and feeds a machine learning surrogate pipeline — replacing computationally expensive finite-element runs with fast predictive models.

The work progressed through six iterative research phases, from baseline model development to identification of novel transport mechanisms, culminating in a Bayesian-guided smart optimization framework targeting sub-0.5 mg/day prediction error.

Challenge & Approach

Core Challenges

  • CFD model systematically underpredicted osmotic agent release, cascading into errors for the active drug prediction
  • Dynamic solid–liquid interface during dissolution creates a time-varying flow cross-section not captured by standard models
  • Drug solubility is a nonlinear function of pH, co-solute concentration, temperature, and polymer content — all varying with time
  • Parametric design space is large; exhaustive CFD sweeps are computationally prohibitive for industrial timescales
  • Particle density analysis contradicted industry's proposed solid-phase transport hypothesis — requiring new mechanistic explanations

Methodological Approach

  • Built a 2D COMSOL model coupling Navier–Stokes, convection–diffusion, dissolution ODEs (PBM), and osmotic pressure physics
  • Identified S–L interface as a time-dependent convective modifier; derived and implemented a dynamic flux coefficient function
  • Introduced variable solubility models (function of concentration, pH, temperature) replacing fixed scalar assumptions
  • Automated full simulation pipeline via Python–COMSOL API: parameter selection → simulation → auto-save → RMSE evaluation
  • Designed Bayesian smart optimization loop (3-point initialization → adaptive sampling → convergence to target RMSE < 0.5 mg/day)
  • Roadmapped ML surrogate layer (Random Forest + PINN) trained on CFD dataset to replace expensive parametric runs

Novel Physics · Transport

Solid–Liquid Interface Discovery

  • Identified a previously unmodeled mechanism: dissolution progressively changes the fluid cross-section, dynamically altering convective flux
  • Early-stage narrowing amplifies velocity and convective transport; later widening reduces it — a time-dependent modifier not in standard models
  • Formulated and validated a dynamic convective flux coefficient as a function of time, significantly improving prediction accuracy

Solubility Modeling · RMSE

Variable Solubility & RMSE Validation

  • Replaced fixed scalar solubility assumptions with dynamic functions: Urea solubility as a function of local concentration, Gem-HCl as a function of pH and Urea mass fraction
  • Variable solubility model achieved lower RMSE for both drug and osmotic agent release profiles against experimental dissolution data
  • Closed the mass balance for the osmotic agent, previously showing 35 mg overestimation in the constant-solubility model

Force Analysis · Hypothesis Testing

Particle Transport & Hypothesis Validation

  • Rigorously evaluated the industry hypothesis that solid particles exit the device through the orifice as a transport mechanism
  • Force balance (gravity, buoyancy, pressure-driven drag) showed osmotic agent particles are non-buoyant — gravity exceeds buoyancy, contradicting the proposed mechanism
  • Pressure-driven convective flow identified as the dominant ejection mechanism; findings redirected modeling effort to convective flux improvements

Key Achievements

2D Multiphysics Model — Full Physics Coupling Delivered a validated 2D CFD model coupling Navier–Stokes, convection–diffusion, Population Balance dissolution ODEs, and osmotic pressure physics for a complex dual-compartment device with 2576 structured mesh elements.
Novel Mechanism Identified — Dynamic S–L Interface Discovered and formulated a previously unmodeled time-dependent convective flux modifier arising from the evolving solid–liquid interface during dissolution — resolving systematic underprediction that persisted across all prior modeling attempts.
Fully Automated CFD Pipeline — Zero Manual Intervention Built a Python–COMSOL API integration in Jupyter Notebook enabling automated parametric sweeps over arbitrary parameter lists or ranges, with automatic RMSE evaluation and .mph file archiving after every run.
Hypothesis Tested & Resolved — Particle Transport Mechanism Performed a complete force balance analysis (gravity, buoyancy, pressure-driven drag) on solid particles, rigorously disproving the industry's proposed solid-phase transport hypothesis and redirecting the modeling effort toward the correct convective mechanism.
ML Surrogate Architecture Designed & Roadmapped Architected a two-tier surrogate system (Random Forest + PINN) using CFD-generated parametric datasets as training data, targeting replacement of computationally expensive finite-element sweeps with fast predictive inference models.
Mass Balance Closure — Variable Solubility Model Implemented dynamic solubility functions (Urea as f(concentration), Gem-HCl as f(pH, Urea mass fraction)) replacing fixed scalar inputs — closing the osmotic agent mass balance and reducing RMSE for both drug and agent release profiles simultaneously.
